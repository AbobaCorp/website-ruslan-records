# Руслан Камазов Records

Официальный (шуточный) сайт артиста **Руслана Камазова** — легенды прогулов, короля будильников, которые не слышно, и человека, который «уже выехал».

Сайт сделан в стиле музыкального лейбла: дискография из пропусков, тур по аудиториям, мерч и заявки на появление на паре (которые, конечно, отклоняются).

## Что внутри

- **Экран загрузки** — «Руслан просыпается…» с прогресс-баром и кнопкой «Пропустить»
- **Бегущая строка** со срочными новостями из деканата
- **Hero-секция** с портретом и интерактивной цепью «R» (будильник)
- **Дискография прогулов** — альбомы и синглы вроде «Будильник не слышу», «Староста, не пиши»
- **Тур «Где ты?»** — расписание пар с статусами Sold out / Отмена · спит
- **Фото из студии** (кровать)
- **Статистика карьеры** — живой счётчик пропусков, посещаемость 3%, уровень лени ∞
- **Отзывы** от препода, старосты, деканата и мамы
- **Мерч** — худи «Я на паре» (нет), цепь «R», справки о болезни
- **Форма заказа** Руслана на пару (с гарантированным отказом)

Интерактив:
- Кнопка «Слушать» выдаёт ошибки 404
- Клик по цепи / кнопка будильника — звуковой сигнал «ПОДЪЁМ!»
- Кнопка «Купить всё» убегает от курсора
- Заявка на пару всегда отклоняется с новой причиной

## Как запустить

Просто открой `index.html` в браузере — сервер не нужен.

Или локально через любой static-сервер:

```bash
# Python
python -m http.server 8000

# Node (если установлен)
npx serve .
```

Затем открой http://localhost:8000

## Технологии

- Чистый HTML5 + CSS3 + Vanilla JS
- Google Fonts: **Oswald** + **Rubik**
- Web Audio API для «будильника»
- Адаптивная вёрстка (мобильная версия)
- `prefers-reduced-motion` — уважает настройки доступности

Никаких фреймворков, сборщиков и зависимостей.
